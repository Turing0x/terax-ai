# Terax: notas de contribución (Turing0x)

Documentación propia de nuestro trabajo sobre [crynta/terax-ai](https://github.com/crynta/terax-ai).
Vive en la rama huérfana `contrib-notes` del fork `Turing0x/terax-ai`: no comparte historia con
upstream y nunca forma parte de un PR.

| Fichero | Contenido |
| --- | --- |
| [STATUS.md](STATUS.md) | Estado actual, fases del plan, PRs abiertos y cerrados, próximos pasos |
| [PROJECT.md](PROJECT.md) | Qué es Terax, stack, arquitectura y dónde vive cada cosa |
| [RULES.md](RULES.md) | Reglas del mantenedor y checklist antes de abrir un PR |
| [WORKFLOW.md](WORKFLOW.md) | Setup local: remotes, worktrees, ramas, comandos |
| [AUDIT.md](AUDIT.md) | Hallazgos de la auditoría (pendiente / en curso) |
| [BACKLOG.md](BACKLOG.md) | Ideas, observaciones y funcionalidades a proponer |

Fuente de verdad del proyecto: `TERAX.md` en upstream. Estas notas lo resumen y registran
nuestro progreso; si algo choca, gana `TERAX.md`.
